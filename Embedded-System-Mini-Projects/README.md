# Embedded System Mini Projects

A collection of microcontroller-based mini-projects developed using Embedded C, ARM7/LPC21xx peripherals, and hardware interfacing.

## Projects

| No. | Project | Controller | Main concepts |
|---|---|---|---|
| 01 | [UART Controlled LED with LCD Status](Mini-Project-01-UART-LED-LCD/) | LPC21xx family (diagram supplied shows LPC2138) | UART0, GPIO, 16x2 LCD, Timer0 |

More projects will be added as they are completed and tested.

## Repository structure

- `Mini-Project-01-UART-LED-LCD/` – source code, driver files, documentation and project setup notes.

## Notes

The source code is provided as an educational project. Confirm the exact MCU, clock configuration, pin connections and LCD supply requirements for your development board before programming physical hardware.
